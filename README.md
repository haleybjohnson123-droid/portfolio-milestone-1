# Portfolio Milestone 1

This project is a small static portfolio website for Haley Johnson, built with HTML and CSS. It includes a home page, project/work page, and about/contact page with a dark, moody visual style.

## Included pages

- `index.html` — landing page and portfolio introduction
- `projects.html` — projects/work section
- `about.html` — personal bio and contact details
- `style.css` — shared styling for the site
- `onedarkwindow.jpg` — site image asset
- `Idea Board.pdf` — supporting project document

## Local preview

Because this is a static site, you can view it by opening `index.html` directly in a browser.

If you prefer using a local server:

```bash
cd "C:\Users\HaleyJohnson\Desktop\Skeleton"
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Project purpose

This portfolio showcases Haley's background, interests, and personal brand while learning front-end development and IT work.
